# Plan

One `COMMON` preamble shared by every task, carrying the two rules a dispatched
agent must have even if it loads no skill: read everything first (FRD-003 T9,
including reference files and group context), and the headless rule (FRD-009 R3
— take the reasonable option, record the question and assumption, never guess
forward across a second dependent decision).

That placement is the point. A dispatched agent may never load a skill; the
prompt is the one layer that always arrives, so the rules that cannot be missed
belong there rather than only in skill prose.

Each task states its deliverable as something that either exists on disk or does
not — "at least one document under research/", not "the research is adequate".
An unfalsifiable done-condition cannot end a background run.

`takeTicketPromptText` stops describing research → impact → plan → proof. That
sequence is now per-profile, so the prompt points at `get_doc_gates` instead of
restating a pipeline that is wrong for three of the four shipped profiles.
