The GUI persists a default OpenAI tunnel profile with intentionally empty tunnel/executable/credential fields during registration, but readOpenAITunnelSettings later requires every persisted profile to be fully runnable. After restart the app throws OPENAI_TUNNEL_SETTINGS_INVALID before the operator can complete, reconcile, or remove the profile. Make the reader accept the product-owned incomplete/default state while continuing to reject malformed or unsafe populated fields.
