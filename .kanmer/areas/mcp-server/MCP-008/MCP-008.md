## What
Headless board serve plus a `.mcpb` bundle so Claude Desktop and other MCPB-capable hosts connect to a Kanmer board without the GUI running.

## Why
Desktop hosts need a supported connection path that does not depend on relocating the runtime and does not require the Electron app to be open.

## Approach
- Serve the existing board through the standard entry points; no dependency on moving `kanmer-mcp.cjs`.
- Package a `.mcpb` bundle for Claude Desktop; document install.
- Coordinate with the Streamable HTTP transport ([[MCP-025]]) — one transport story, no duplicate transports.

## Verification
- [ ] Claude Desktop connects via the `.mcpb` bundle to a real board with the GUI closed
