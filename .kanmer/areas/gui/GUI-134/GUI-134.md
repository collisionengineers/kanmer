Installed v0.3.7 production UI/IPC reproduction: saving a valid Cloudflare configuration creates a non-null config generation, but the preload remoteCreateSecret bridge accepts only project and rotate and drops the expected generation required by the main handler. Every Create token attempt then fails with REMOTE_CONFIG_VERSION_CONFLICT. Preserve optimistic concurrency; pass the current generation through the typed renderer/preload contract and add a real bridge-level regression.
