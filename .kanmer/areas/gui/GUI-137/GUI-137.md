Exact-merge packaged reproduction: configStore canonicalizes persisted project ids to lowercase forward-slash paths for auto-start, while opened-project IPC passes the display-form Windows path. RemoteAccessManager keys records, queues, deliveries, and status correlation by the raw string, so auto-start owns a healthy canonical runtime but UI Start/doctor creates a duplicate stopped record and fails REMOTE_OWNER_EXISTS. Canonicalize project ids at the manager boundary and prove autostart/open/manage share one runtime.
