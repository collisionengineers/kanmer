## Why\n\n`get_execution_packet` rejects a ticket already taken by its recorded assignee, even when its branch and worktree are the exact execution target. This prevents a paused/review-remediation run from resuming safely.\n\n## Outcome\n\n\n## Verification\n\nThe recorded assignee can receive a resume packet for the exact recorded worktree; a different assignee remains blocked.
