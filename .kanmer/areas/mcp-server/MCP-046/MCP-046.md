## Outcome\n\nThe native Antigravity plugin descriptor must launch the installer-owned Kanmer shim through the exact argument form that agy accepts on Windows.\n\n## Evidence\n\nThe merged descriptor with an escaped quoted /c argument fails a real agy bound get_status session even when the launcher exists. A disposable descriptor variant without the embedded escaped quotes installs successfully and the same agy session returns KANMER_AGY_GET_STATUS_OK. Implement the smallest descriptor/test fix, preserve shell-safe paths, and re-run independent hosted and real-host evidence.
