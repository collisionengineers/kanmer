## What

Prove remote access end-to-end through the named Cloudflare Tunnel using a disposable Cloudflare Worker as the external MCP client: tunnel → HTTPS `/mcp` → Kanmer bearer → ticket lifecycle → doctor → teardown.

## Approach

- Deploy a disposable Worker client only; it is not a hosted Kanmer MCP server, proxy or relay.
- Supply the endpoint and expected project separately from the bearer, and keep the bearer solely in a Worker secret binding.
- Initialize MCP, verify the expected project and tool surface, create/update/archive a disposable ticket, close the session, and retain only redacted status evidence.
- Require no Cloudflare Access headers, cookies, redirects or identity flow; delete the Worker and secret after proof.

## Verification

- [ ] Proof records the redacted remote Worker interaction, public doctor result, archived disposable ticket and complete provider/secret teardown.
