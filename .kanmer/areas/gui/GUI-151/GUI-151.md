## What

Create a self-contained HTML mockup that reproduces the current Kanmer desktop UI and can be opened directly in a browser. Seed it with realistic fictional projects, tickets, documents, activity, settings, and agent state.

## Why

A portable, fully interactive mockup makes the Electron interface easy to demonstrate and evaluate without launching the packaged application or connecting a real board.

## Approach

- Reuse the current renderer's visual language and interaction model.
- Keep the deliverable self-contained with no runtime dependencies.
- Implement the visible workflows against in-memory seeded data.

- [ ] Open the HTML file in a browser and exercise board, ticket, filter, search, view, theme, and settings interactions.
