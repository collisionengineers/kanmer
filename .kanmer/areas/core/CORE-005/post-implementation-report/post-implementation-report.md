# Post-implementation report

Proof carries a flavour and, optionally, a source. The hard gate is unchanged —
≥1 document under `proof/` — and everything added is advisory.

**For review:** the image check is deliberately shallow (extension match under
`proof/`, recursively). It will not notice a screenshot of the wrong thing, and
it is not meant to. Anything sharper would start blocking work on a heuristic,
which is exactly what FRD-006 R4 rules out.
