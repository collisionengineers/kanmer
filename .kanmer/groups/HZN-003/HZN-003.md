Everything not yet done, targeted at the **0.3.4** release.

Two strands, and they are not equally urgent:

**Polish the shell.** A run of small things that all read as "this app is
sloppy" to someone using it for the first time — Backlog rendered as the last
column, a Backlog tab counting the whole board, checkboxes floating away from
their labels, a bare `?` in Settings, and Antigravity mislabelled as if it were
less capable than it is. Individually trivial; collectively they are most of the
first impression.

**Finish what 0.3.2 started.** The updater work left real debt: the automatic
update path has never run unaided, the release script keeps letting incomplete
uploads through, the root typecheck does not cover every workspace, and the MCP
server still lives inside the folder every update replaces.

Shared context worth reading once: several of these come out of [[GUI-064]],
whose proof.md is explicit about what it did and did not establish.
