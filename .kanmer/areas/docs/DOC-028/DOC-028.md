## Problem

The canonical managed block (`scripts/agents-block-body.mjs`, mirrored into every consuming repository's AGENTS.md and the `kanmer-setup` skill) pushes every session toward ticket discovery and the full skill sequence, tells agents to "read the whole ticket folder", and says proof is written on merged `main` even though the delivery policy (FRD-031, `resolveDelivery`) supports another integration branch. A read-only explanation or a supplied-mockup review therefore tends to spawn tickets and worktrees, a small chore invites feature-sized research, and a repository whose integration branch is not `main` gets contradictory instructions. There is also no stated rule that one heavy verifier owns expensive builds on a host.

## Outcome

The block resolves the request before starting a workflow (direct work vs tracked work; profile by consequence, not size), names the configured integration branch via `get_status → delivery.integrationBranch` instead of a literal `main`, states that ordinary Done means integrated (deployment belongs to a release or a deployment-scoped ticket), tells agents to load only what the current step needs, and names one heavy verification owner per host. The 24 conduct rules and the board-branch paragraphs are unchanged. Every mirror and check stays byte-consistent.

## Acceptance

- A read-only mockup discussion creates no ticket or worktree; an ordinary revert does not invoke seven roles; a two-line authorization change still owes its profile's evidence; a fix can finish on a configured non-`main` integration branch — each expressed as a prose assertion in the block and pinned by a test.
- `scripts/verify-agents-block.mjs` gains checks that the body contains no "merged `main`" proof claim, names `delivery.integrationBranch`, contains the routing sentence, the heavy-owner sentence and the deployment-separation sentence; existing checks 1–9 (24 rules, 4 groups, byte-identical skill copy, GUI re-export) stay green.
- `npm run verify:skills`, `npm run plugin:build`, `npm run plugin:check`, `npm run verify:docs` green; CORE-139's no-escaping-link check preserved.
- This repository's AGENTS.md block regenerated with `node scripts/agents-block.mjs .`.

## Out of scope

A natural-language policy engine; rewriting other repositories' AGENTS files; per-repository templating of the block (the fenced skill copy is static prose); the CLOSEOUT_PLAN.md retirement (that is [[DOC-026]]).
