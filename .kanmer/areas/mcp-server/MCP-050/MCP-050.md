In a genuine clone with no .kanmer data, they fail before their intended assertions. Make these tests provision and pass explicit disposable board roots so npm run verify is hermetic. Preserve the clean-clone failure on CORE-103; do not bypass it with a machine-specific KANMER_ROOT.
