## Goal

The deeper upgrade after [[HZN-009]]: durable receipts and efficient selection, safe workspace lifecycle automation, readable tickets with typed terminal outcomes, optional source capability bindings, the retained interoperability fixes, Focus Board detail/interaction parity and qualification, a supported Electron runtime with re-qualified IPC/sandbox boundaries, local (not abstract) core maintenance, and a smaller measured skill surface.

## What binds this batch

- Extend existing schemas, proof/reconciliation paths and the source registry; never build a parallel source of truth.
- Backward-compatible readers before new writers; unknown-field preservation tested on copies.
- Cleanup is dry-run first, protects dirty/foreign/board/locked workspaces, and requires an explicit terminal disposition — a lease timer never replaces process and Git checks.
- Migration never converts non-PASS into PASS or rewrites historical release results.
- No mandated cloud, framework migration, new database or per-ticket deployment.

Carried-over R1 criteria are recorded on each member ticket, not inferred. MCP-052 stays owner-parked outside this horizon.
