Real v0.3.10 setup sent the operator to ChatGPT's Custom Connector URL flow with `https://mcp.rivetandrelay.co.uk/mcp`. Kanmer advertises only static bearer auth there, so ChatGPT correctly demanded OAuth client credentials and endpoints that Kanmer does not implement. Meanwhile the OpenAI Secure MCP Tunnel created discoverable personal Kanmer apps in ChatGPT's Plugins > Personal surface. Make both GUI/manual paths explicit: Cloudflare is for bearer-capable MCP clients and must not be presented as a ChatGPT custom connector; ChatGPT uses the OpenAI tunnel and installs the discovered personal Kanmer app while the runtime is ready. Provide actionable status without claiming OAuth support. FRD-026 on current main governs the OpenAI GUI path and must be linked when the source checkout is current.
