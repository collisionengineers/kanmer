## Approach

- Deploy a disposable Worker client only; it is not a hosted Kanmer MCP server, proxy or relay.
- Supply the endpoint and expected project separately from the bearer, and keep the bearer solely in a Worker secret binding.
- Initialize MCP, verify the expected project and tool surface, create/update/archive a disposable ticket, close the session, and retain only redacted status evidence.
