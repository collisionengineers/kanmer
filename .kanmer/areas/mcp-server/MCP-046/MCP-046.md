## Outcome\n\nThe native Antigravity descriptor now launches the installer-owned Kanmer shim through the exact argv form that agy accepts on Windows. PR #231 is open for independent review at commit d63495a1.\n\n## Evidence\n\nThe merged descriptor with an escaped quoted /c argument failed a real agy bound get_status session even when the launcher existed. A disposable descriptor variant without the embedded escaped quotes installed successfully and the same bound session returned KANMER_AGY_GET_STATUS_OK with exit 0. The PR adds the smallest descriptor change, plugin-sync assertion, and dependency-free regression.\n
