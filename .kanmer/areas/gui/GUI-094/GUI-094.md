## What

Replace Kanmer's machine-specific Codex Connect registration with one byte-identical project registration that works across supported Windows machines, usernames, drives, selected Kanmer install directories, and checkout locations.

The committed registration launches Windows `cmd.exe` and a fixed installer-owned shim under `%LOCALAPPDATA%\Kanmer\bin`. The shim resolves the selected Kanmer installation through HKCU and preserves Codex's workspace cwd so ADR-0012 discovers the correct canonical board worktree and source repo.

This is Codex-specific. Claude Code, OpenCode, Grok, Antigravity, plugin installation, and dispatch retain their current contracts.

## Why

Pegasus currently tracks a generated registration containing one user's absolute `Kanmer.exe`, bundled MCP, source checkout, and `.worktrees/kanmer` paths. It cannot work unchanged on another machine. Gitignoring future generated files, as GUI-083 did, does not repair already tracked files and does not make project configuration shareable.

OpenAI Docs supports trusted project `.codex/config.toml` and stdio `command`/`args`/`env`/`cwd`, but does not document MCP paths as relative to the declaring config. Kanmer therefore needs an explicit installed launcher contract rather than an assumed relative path.

## Verification

- The exact committed Codex entry contains only `cmd.exe` and the quoted `%LOCALAPPDATA%\Kanmer\bin\kanmer-mcp.cmd` command string.
- It contains no username, drive, selected install directory, repository path, board-worktree path, `Kanmer.exe` path, MCP bundle path, `--root`, `--repo-root`, or project `cwd`.
- One byte-identical config calls `get_status` successfully from two differently located trusted repositories and from a linked ticket worktree.
- Each call resolves that repository's canonical board worktree and source root through discovery.
- Custom-directory install, probe, upgrade, and uninstall preserve ownership of the fixed shim and HKCU value.
- Normal wrapper startup emits no non-MCP stdout and returns the child exit status.
- A failed launcher probe cannot create or overwrite project config and gives an actionable repair.
- Claude Code, OpenCode, Grok, and Antigravity invocation/config fixtures remain unchanged.
- Reconnect stays idempotent, preserves unrelated TOML, keeps Codex trust guidance, and safely drains eligible legacy global entries.
