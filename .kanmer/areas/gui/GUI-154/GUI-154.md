## Problem

On the operator host (Windows 11, Node v24.15.0, vitest 2.1.9, tinypool 1.1.1, `vitest run --no-file-parallelism`, forks pool) the `@kanmer/gui` suite intermittently dies with `Error: Worker exited unexpectedly` (tinypool `ChildProcess.onUnexpectedExit`) immediately after the last test of `apps/gui/src/main/kanmerGit.test.ts` (`ensureBoardWorktree reconciliation > is idempotent once the worktree is on the branch`) prints its tick — during worker teardown, never inside an assertion. No JS heap OOM signature; a 4 GB `--max-old-space-size` changes nothing. Observed 2026-09-05 during the 0.4.2 cut: full `npm run verify` failed 3/3 at that point (attempts 1–2 with 1,689 stale `kanmer*` temp boards and a 96%-full disk; attempt 3 after cleanup), while standalone `npm run test -w @kanmer/gui` failed 2/2 before the temp cleanup and passed 2/2 after it (including with `KANMER_ROOT` set as the rail does). Hosted `windows-latest` Node 24 runs of the same suite passed on every push today. The worker exit is consistent with the libuv exit-time assertion the repository already documents in `scripts/release.mjs` ("Assertion failed: !(handle->flags & UV_HANDLE_CLOSING), src\win\async.c") when a Node process exits while child-process or socket handles are still closing — here the vitest fork exits right after the last real-git test while `git` child handles from `afterEach`'s `rm(..., maxRetries)` teardown are still being torn down.

Also observed: each GUI suite run leaves a few `kanmer*` disposable directories behind in `%TEMP%` (1 → 5 across one run); over a day of runs that accumulated to 1,689 directories and contributed to the disk pressure.

## Outcome

The GUI suite exits cleanly on Windows after `kanmerGit.test.ts` regardless of host timing, and disposable temp boards are removed by the tests that create them.

## Acceptance

- Root cause named with evidence (which handle is still open at worker exit; whether the pool mode or an explicit `afterAll` drain fixes it); no assertion weakened.
- Ten consecutive local `npm run test -w @kanmer/gui` runs and one hosted run pass; the full `npm run verify` rail passes locally on the operator host.
- `kanmer*` directory count in `%TEMP%` is unchanged after a GUI suite run (every `mkdtempSync` in `apps/gui/src/**/*.test.ts` has a matching removal, including on failure paths).

## Out of scope

Changing the test framework; skipping real-git tests on Windows.

## Technical seam

`apps/gui/src/main/kanmerGit.test.ts` (`beforeEach`/`afterEach`, `realGitTest`), `apps/gui/src/main/kanmerGit.ts` child-process handling, `apps/gui/package.json` `test` script / vitest pool options, `scripts/run-tests.mjs`.
