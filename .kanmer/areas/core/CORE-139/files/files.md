## Ripple effects

- Every repo set up by Kanmer will report `agents-block: behind` after this ships (the body changed); that is the intended signal and `kanmer-setup` reconciles it.
- The operator-installed `board-regate.yml` on `kanmer-board` keeps dispatching until re-copied; with the `verify.if` fix alone the dispatches become cheap (regate only).
- `scripts/pr-workflow.test.mjs` runs inside `npm run test:scripts` (part of `npm test`).
