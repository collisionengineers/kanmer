## Root-cause class statement

The 34 prior findings plus F-035 and F-037 are dominated by one class: **parsing authority — the grammar by which plan and checklist prose acquires machine authority over files and steps.** This batch resolves that class by narrowing the grammar at each of its three surfaces to one exact, single-source rule instead of patching examples: one `classifyPlanPath` for path-vs-symbol spans, one `namedChecklistStep` for named checklist markers, and one exact `### Step N — <title>` heading form with a contiguity check for structured steps. Each rule is stated once in code, pinned by a fixture table, and published in AGENTS.md, `kanmer-plan`, `kanmer-execute`, `kanmer-auto` and the tool reference with matching `verify-skill-prose.mjs` assertions, so the contract and the parser cannot drift apart. F-032 belongs to a second, smaller class — **evidence completeness across intervening history** — closed by reading modes rather than names from every tree edge. F-038 and F-039 are the residue of the first class on the *authoring* side: what a plan author may write in `## Do not modify` and how strictly it is read. Both are fail-safe, neither is a regression from this batch, and per the root-cause rule they are recorded once as one class for a single documentation/follow-up decision — not patched as two more examples inside a batch whose budget is spent.
