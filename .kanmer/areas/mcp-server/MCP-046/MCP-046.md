## Outcome

Merged PR #231 (https://github.com/collisionengineers/kanmer/pull/231) at 8554c733aac5817e99909622e062d022d6c12be3. The native Antigravity descriptor launches the installer-owned Kanmer shim through the exact quote-free delayed-expansion argv form that agy accepts on Windows. The descriptor captures the provider cwd, uses a temporary pushd into the installer bin, and the shim restores the provider cwd before MCP starts. ADR-0012 now documents the explicit restoration exception.

## Evidence

The embedded-quoted descriptor failed a real agy bound get_status session because cmd.exe received quote characters literally. A direct unquoted path failed with a spaced LOCALAPPDATA. Merged-main verification passed launcher/config 8/8, GUI Connect 35/35, script rail 98/98, plugin:check, GUI typecheck, and diff check. The installed native plugin proof returned KANMER_AGY_FINAL_PUSHDCALL_OK. No follow-up ticket was created; deployment is n/a.
