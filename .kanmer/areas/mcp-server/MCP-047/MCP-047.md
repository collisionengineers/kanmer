## What

Correct the generated locally managed Cloudflare Tunnel ingress so Cloudflare forwards the client `/mcp` path unchanged rather than rejecting an origin service URL containing `/mcp`.

## Why

The installed `cloudflared` 2026.8.2 rejects `service: http://127.0.0.1:<port>/mcp` during `tunnel ingress validate`. The same configuration with `service: http://127.0.0.1:<port>` validates and routes a public `/mcp` request to the local MCP endpoint.

## Verification

- [ ] Real cloudflared validates the generated configuration and matches `/mcp` to a loopback origin without an embedded path.
- [ ] Focused adapter tests and relevant verification rails pass.
- [ ] A disposable locally managed tunnel on the approved temporary subdomain reaches public bearer rejection and is fully removed.
