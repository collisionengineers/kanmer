Write the provider-neutral remote-access manual: Streamable HTTP plus bearer flow, adapter model, Cloudflare named-tunnel appendix, generic client guidance, a Cloudflare Worker integration-proof note, and troubleshooting through the doctor. Regenerate the in-app manual.

## Boundaries

- The current Cloudflare path is locally managed named Tunnel plus mandatory Kanmer bearer authentication.
- Cloudflare Access, Quick Tunnels, remote-managed tunnel token mode, account/DNS automation, and Cloudflare Workers-hosted Kanmer are unsupported in this release.
- A disposable Cloudflare Worker is documented only as [[MCP-028]]'s external MCP client proof, never as a deployed Kanmer server or proxy.
- OpenAI Secure MCP Tunnel remains the separate stdio route documented by [[DOC-010]] and managed later by [[GUI-104]].
