The current Grok JSON Configuration importer rejects Kanmer's shipped native plugin descriptor because its stdio command is `${KANMER_NODE:-node}` and the importer now permits only literal `npx` or `uvx`. The repository claims Grok compatibility but targets the Grok CLI/plugin surface, not this current on-device importer. Establish the supported invocation without exposing secrets or machine-specific paths, update the provider contract and user guidance, and prove an actual Grok tool call rather than a listing.
