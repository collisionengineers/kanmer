## Ripple effects

- HTTP readiness (`http.ts` via `projectFingerprint()`) keeps returning the fingerprint; may add `project_id` — additive.
- GUI: reads core only; `project.json` is ignored by the GUI today. `kanmerGit.ts` orphan-cleanup test is a known host quirk — do not touch.
- CI `kanmer-gate` (`check-pr.mjs`) reads the board worktree read-only; a `project.json` on the board branch is inert to it.
- Live board (stable v0.3.12): no file in `.kanmer/` is rewritten by this change until an operator runs the candidate against it; when that happens only `project.json` is added.
