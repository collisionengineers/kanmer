## Archived as a duplicate of [[GUI-085]]

Third independent filing of the same defect — `apps/gui/src/main/kanmerGit.test.ts`
timing out non-deterministically (5 s vitest default against real git subprocesses,
plus Windows `EPERM` on temp-dir teardown). [[GUI-086]] was the second and is also
archived.

**[[GUI-085]] is the one to work.** It carries the measured per-test timings, which
give the sharpest diagnosis: four of seven tests already run *longer than the
timeout they are given* (4.6–8.7 s) and pass only because the timer races the git
process. That reframes it from a flake to a mis-specified suite.

This filing's own contribution — that it fails on the parent commit `6c3ae77` and
passes 3/3 on merged main — is one more instance of the pattern already recorded
on GUI-085's `corroboration` note.

**That the same ticket has now been filed three times is itself the finding.** Six
agents hit this during the HZN-003 auto run, on six unrelated diffs, and each one
independently spent real time proving it pre-existing before it could trust its own
rail. Three of them concluded it deserved a ticket and filed one, because none
could see the others' work. The duplication is a cost of parallel lanes, but the
underlying tax — six separate diagnoses of one defect — is the argument for fixing
it promptly rather than living with it.

Archived rather than deleted, per the board's convention.
