## What

Make the committed plugin MCP bundle reproducible from a normal checkout when the source change was implemented in a linked ticket worktree.

## Why

Merged [[MCP-022]] passes source verification but fails the required normal-checkout `npm run plugin:check`: rebuilding in the root changes 514 comment-path lines in `plugins/kanmer/mcp/kanmer-mcp.cjs` (`../../../../node_modules` from a linked worktree versus `../../node_modules` from root). This leaves a false/stale bundle and blocks its proof.

## Acceptance

- A linked-worktree implementation can commit an artifact that is byte-identical to a fresh normal-checkout build, or the build/check flow explicitly makes that outcome deterministic.
- On merged main, `npm run build && npm run plugin:check` passes with a clean tree.
- Preserve plugin runtime/module resolution and do not modify [[MCP-022]] source behavior.
