## What

`logo.png` (750 KB) and `icon.png` (1.3 MB) are sitting loose in the repo root.
Move them somewhere structural and actually use them.

## Why

The repo root is not an asset directory, and two unreferenced megabyte PNGs
there read as forgotten rather than deliberate. More to the point they are not
used: the app, the installer, the README and the plugin manifests all present
Kanmer without them.

## Approach

- Find the homes each build actually reads from — electron-builder's icon
  configuration, the renderer's asset path, the plugin manifests, the README —
  rather than inventing a directory and hoping.
- **Check the source sizes are appropriate before wiring them in.** 1.3 MB is
  large for an icon; Windows wants a multi-resolution `.ico`, and shipping an
  oversized PNG into the installer is a regression dressed as a feature.
- Decide the split deliberately: `icon` for the app/installer/tab, `logo` for
  the welcome screen, README and marketplace listings. They are not
  interchangeable.
- Anywhere the product currently shows a placeholder or a bare wordmark is a
  candidate; the welcome screen is the obvious one.

## Verification

- [ ] Neither PNG remains in the repo root.
- [ ] The built app and installer carry the real icon — checked on the packaged
      output, not the source tree.
- [ ] The logo appears where a user sees it, with a screenshot as proof.
- [ ] Installer size has not grown unreasonably.
