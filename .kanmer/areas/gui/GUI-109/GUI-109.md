## What

Implement the documented “Add to group” action in the ticket ContextMenu, preserving existing group chips, filters, and membership semantics.

## Why

The historical GUI-013 record claims the action is wired, but the current context menu has no Add to group action. Group membership is ticket frontmatter updated through the existing MCP/core contract.

## Verification

From a ticket card context menu, choose Add to group, select an existing group, save, and prove the chip/filter and derived group membership update after reload. Preserve existing groups and reject unknown groups.

## Non-goals

No new group storage model, duplicate membership list, or unrelated board/menu redesign.
