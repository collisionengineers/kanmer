## Outcome

The native Antigravity descriptor now launches the installer-owned Kanmer shim through the exact quote-free delayed-expansion argv form that agy accepts on Windows. PR #231 is open for independent review at commit 49612bfb.

## Evidence

The embedded-quoted descriptor failed a real agy bound get_status session because cmd.exe received quote characters literally. A direct unquoted path failed with a spaced LOCALAPPDATA. The final descriptor captures the provider cwd, uses a temporary pushd into the installer bin, and the shim restores the provider cwd before MCP starts. A regression executes the shipped shim logic and proves final CWD/provider marker remain the provider workspace. ADR-0012 now documents the explicit restoration exception. The installed native plugin proof returned KANMER_AGY_FINAL_PUSHDCALL_OK. Hosted kanmer-gate and verify passed on the prior exact head; this documentation-only push reruns them.
