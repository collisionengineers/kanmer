## Why
GUI-147 added `verifyInstalledMarketplaceVersion()` (`apps/gui/src/main/connect.ts`), which parses only the `Version:`/`Scope:` lines of `claude plugin list`. On this machine on 2026-09-03 `claude plugin list --json` reported `kanmer@kanmer` version `0.4.0`, `enabled: true`, `errors: ["Marketplace kanmer failed to load: cache-miss"]` — the exact state GUI-147 exists to end — and the current check would have passed it. `claude plugin list --json` is documented and exposes `id`, `version`, `scope`, `enabled`, `errors[]` per entry.

## Outcome
- Claude's `installedVersion` check runs `claude plugin list --json`; the parser returns `{ version, scope, enabled, errors }` for the `kanmer@kanmer` user-scope entry, with the existing text parser (extended with `Status:`/`Error:` lines) as fallback for non-JSON output.
- Connect fails (`ok:false`, pasteable repair command, host error quoted) when `errors` is non-empty or `enabled` is false, even if the version matches.
- `SkillsStatus` gains `hostError: string | null`; Settings shows "plugin failed to load" beside the version hint so the panel cannot look healthy over `cache-miss`.
