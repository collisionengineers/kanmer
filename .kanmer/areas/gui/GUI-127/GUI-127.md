## What

The authoritative Windows `npm run verify` rail fails in `apps/gui/src/main/kanmerGit.test.ts`: two `renameBoardBranch` cases exceed the default 10-second hook timeout, then cleanup hits `EPERM` while removing their temporary real-Git fixture directories. This blocks ticket verification and release workflows.

## Scope

Make fixture teardown deterministic on Windows without weakening product assertions, hiding child-process failures, or changing production worktree behavior. Capture a repeatable local Windows verification result and the hosted CI result.

- [ ] The focused real-Git suite passes repeatedly on Windows without leaked temporary fixture directories.
- [ ] `npm run verify` passes locally and on the PR's Windows workflow.
