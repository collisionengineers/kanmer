## What

Reject whitespace-padded scratch-note names exactly as entered in the GUI editor.

## Why

GUI-096 originally trimmed the proposed name before validation, so `" note "` became `note`. Its approved plan requires invalid input not be silently transformed before writing.

## Resolution

Remediated in [[GUI-096]] PR #91 by commit `b6ad3da`: validation now uses the exact entered value and a renderer regression test verifies padded names do not open `scratch/note` or write a document.
