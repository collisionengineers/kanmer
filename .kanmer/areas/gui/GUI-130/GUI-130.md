## What

The GUI sync integration suite passes when isolated (11/11) but took roughly 95 seconds on Windows. In a normal-clone full `npm run verify`, `src/main/index.sync.test.ts` instead failed an `afterEach` hook at the existing 10-second bound. The failure occurred after the core suite passed and is independent of the atomic settings-write scope in [[GUI-129]].

## Scope

Reproduce the difference between isolated and full-rail Windows runs, then make the GUI test execution deterministic without weakening assertions or converting timeout failures into passes. Consider supported test-runner scheduling/isolation only if evidence supports it. Preserve finite hook/test bounds.
