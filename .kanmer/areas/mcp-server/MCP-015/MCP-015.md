## What

Antigravity has a working plugin installer and is dispatchable. Kanmer uses
neither. Split out of [[MCP-009]] and [[GUI-073]].

Measured against the real CLI (`agy` 1.1.13 — note the binary is `agy`; there is
no `antigravity` executable):

- `agy plugin install <dir>` → `skills: 12 processed, mcpServers: 1 processed`
- `agy -p "Reply with exactly the word PONG…"` → `PONG`, exit 0 — so
  `dispatch: false` in `providers.ts` is **refuted**, not merely stale. Two
  independent research agents reached this conclusion separately.

## Why

The plugin installer does in one command what Kanmer currently attempts by writing
a skills directory, and it is the host's own supported mechanism.

Dispatch is the larger win and the larger risk. Flipping `dispatch: true` is not
one line: `dispatch.ts:115` spawns with `cwd: root` and **no project binding**, and
prior research found that a bare `agy` session does not see workspace skills or
workspace MCP servers — only a project-bound one does. So a dispatched Antigravity
agent would run blind to the very MCP server Connect just registered. Enabling
dispatch without establishing a binding would produce an agent that appears to
work and silently cannot see the board.

**Depends on the [[GUI-073]] adjudication.** Two agents disagreed about whether
`.agents/skills/` is read at all, and the answer decides whether the binding is
the gate or whether the directory is simply inert. Do not start until that is
settled and recorded on GUI-073.

## Approach

- Move Antigravity to the plugin install path.
- Establish what project binding Connect and dispatch must set up, from the
  adjudicated evidence, and implement it — or state with evidence that dispatch
  cannot be made to see the board and leave `dispatch: false` with a reason.
- Correct FRD-012's install matrix and `Settings.tsx:405-416` (the blurb and badge
  are both stale).
- Every capability claim carries the command and its output.

## Verification

- [ ] Connect installs Kanmer into Antigravity as a plugin, evidenced by the
      skill and MCP list from a real session.
- [ ] A dispatched Antigravity agent can actually call a Kanmer MCP tool — proven
      by a tool call, not by the process starting.
- [ ] If dispatch cannot see the board, that is recorded with the commands run and
      `dispatch` stays false for a stated reason.
