Use the connector doctor before changing configuration. Run the narrowest mode that answers the question: `config` checks inputs, `local` checks the authenticated loopback path, and `public` adds DNS, TLS, and route checks. A skipped check means a prerequisite failed; it is not a pass. Repairs are bounded guidance, not automatic mutation. Never publish bearer values, provider credentials, session identifiers, raw child output, or machine-specific paths. See [remote access](remote-access.md#run-connector-doctor) for invocation and [the Cloudflare appendix](providers/cloudflared.md#public-verification-and-rollback) for provider-only repairs.

## Doctor checks

The matrix records the safe facts an operator may compare. `Observed` means the redacted field or state to capture; `Expected` means the contract value. Status and logs are the doctor report, GUI health panel, or bounded child-status line—not raw process output.

Expected: one selected project and readable board. | Wrong project, missing board, stale registration. | 1. Open intended project. 2. Repair board through normal Kanmer flow. 3. Reconcile identity. | `config` | Stop if identity is ambiguous or board reads mutate; escalate with ids only. |
| `REMOTE_CONFIG_VALID` | config, local, public / remote | One supported provider and complete remote fields are present. | Observed: provider name, field-presence booleans. Expected: `cloudflared` and all required fields present. | Missing field, unsupported provider, malformed hostname. | 1. Correct the profile. 2. Save. 3. Re-run config. | `config` | Stop on an unknown provider or arbitrary URL; escalate the profile name. |

| `LOCAL_PUBLIC_CONSISTENT` | public / consistency | Local and public health describe one endpoint and generation. | Observed: redacted generation/fingerprint prefixes and state tuple. Escalate. | same mode | Never rerun blindly after a mutation. |

The order is deliberate: later checks depend on earlier checks. A `skipped` result names the prerequisite that failed. Human output is convenient for an operator; `--json` is the stable integration form. Exit code 0 is healthy, 1 reports a failed or warned check, and 2 means the doctor itself could not complete. The report is schema version 1; safe detail fields are allowlisted and raw child output is not a repair input.

## Safe escalation

Keep the endpoint disabled while configuration is invalid. Do not solve a hostname error by disabling TLS, widening the bind address, putting a token in a URL, using a Quick Tunnel for production, or forcing another process's ownership. Capture only the mode, check id, status, safe summary, and redacted repair code. Provider-specific actions belong in the Cloudflare appendix; generic client or project problems belong with the project owner.
