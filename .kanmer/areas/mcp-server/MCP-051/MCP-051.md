Real packaged v0.3.10 validation on Windows showed the locally managed Cloudflare connector reached registered HTTP/2 connections only after the fixed 10-second readiness deadline. Kanmer killed the child at 10 seconds and surfaced TUNNEL_READINESS_TIMEOUT, leaving mcp.rivetandrelay.co.uk at Cloudflare 530 despite valid DNS, credentials, and reachable edge ports. Extend the bounded startup allowance to cover Cloudflare connectivity pre-checks and QUIC-to-HTTP/2 fallback, retain fail-closed readiness, and prove the packaged remote host reaches connected state.
