## Goal

The release after 0.3.3. Opened to hold the `kanmer-auto` rework, which is
process work rather than a shipping defect and was deliberately split out of
[[HZN-003]] so 0.3.3's roster stays finishable.

## What binds this batch

**Auto means auto.** A `kanmer-auto` run completes every ticket in its roster.
The only legal stop is a question only the operator can answer.

Context exhaustion is a physical limit, not a decision point — so the run must
survive it without the operator noticing. That single rule is what both founding
tickets serve: [[SKILL-016]] gives the run durable state on the board, and
[[SKILL-017]] corrects the contract that let a run report a partial roster and
wait.

## Origin

A real run over [[HZN-003]] cleared 3 of 22 tickets and then reported a
checkpoint the skill does not authorise. The roster, target point, lane
partition, skip reasons and four operator answers existed only in one agent's
context, so a context boundary destroyed them. Nothing was written to the board
between tickets.
