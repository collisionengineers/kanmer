## Ripple effects

- **Tool roster:** `remoteHttpToolNames()` gains `list_projects` automatically; `smoke-discovery`/`smoke-headless`/doctor read-only rosters that pin counts must be checked (grep for `38`).
- **GUI:** unchanged. `remoteAccess/manager.ts` matches the ready line on `projectFingerprint` only; extra fields are ignored. GUI-144 will write the registry from `settings.json` facts using the exported helper.
- **CORE-115 lane:** no core file is touched; `claimState`/`Item` fields are consumed as exported at 97dfc9f3. If CORE-115 renames claim fields, the registry's workspace view follows in a later PR.
- **Live board (v0.3.12):** no board file changes; the registry lives in the home dir. Nothing is written by any read.
- **CI `kanmer-gate` / `check-pr.mjs`:** unaffected (board read-only).
