_Rescoped 2026-08-20 per MASTERPLAN adoption._

## What
Define the tunnel adapter contract (create / start / stop / status / url) against FRD-025, and implement cloudflared as the first adapter.

## Why
Remote access is one transport, N tunnels: the Streamable HTTP endpoint is provider-neutral and each tunnel provider is an adapter behind one contract. The OpenAI Secure MCP Tunnel remains a documented manual adapter ([[DOC-010]]), not code in this ticket.

## Approach
- Adapter contract as a small interface consumed by the GUI tunnel lifecycle ([[GUI-095]]) and the connector doctor ([[MCP-027]]).
- cloudflared adapter first: quick tunnel; named tunnels only if the contract demands them.
- No auth logic here ([[MCP-026]]) and no transport implementation here ([[MCP-025]]).

## Verification
- [ ] The cloudflared adapter exposes the local HTTP endpoint end-to-end through the contract
- [ ] The contract is documented in FRD-025; [[DOC-010]] referenced as the manual-adapter example
