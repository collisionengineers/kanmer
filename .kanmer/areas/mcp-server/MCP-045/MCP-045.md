## Outcome

The protected remote-public verifier accepts a descriptor that references bearer material through a local token file while continuing to reject inline secret values. PR [#230](https://github.com/collisionengineers/kanmer/pull/230) merged as `85ace9d16abac4d578f5d16bfd2c6b27e7742783`. No follow-up ticket was created; deployment is not applicable because this is verifier tooling.

## Why

The verifier previously rejected its own documented `tokenFile` reference because its unsafe-key check treated the key name as an inline secret. That prevented the canonical public-tunnel proof from running.

## Verification

Focused remote contract tests, hosted CI, and the canonical protected-environment verifier passed against the exact merged commit. The proof records the transient initial missing-dist failure and Windows stale-lock timeout, followed by successful retries without weakening assertions.
